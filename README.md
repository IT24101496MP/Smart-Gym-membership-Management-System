## Project Description

The Smart Gym Membership Management System is designed to digitalize and streamline the operations of Fat2Fit Wellness Studio. 
This system helps manage gym members, memberships, attendance, payments, and fitness progress efficiently.

---

## Main Features
### 1. Client Registration
- Register new gym members
- Store personal details securely
- Update and manage member profiles

### 2. Membership Management
- Create and manage membership plans
- Track membership start and expiry dates
- Renew memberships

### 3. Attendance Tracking
- Record daily attendance
- Monitor member visit frequency
- Generate attendance history

### 4. Payment Management
- Record membership payments
- Track payment history
- Monitor pending payments

### 5. Body Metrics Monitoring
- Record member height and weight
- Maintain historical body measurements

### 6. Fitness Goal Tracking
- Set goals (Weight Loss / Muscle Gain)
- Track goal progress

### 7. Progress Monitoring
- Monitor overall fitness improvements
- View graphical progress reports
